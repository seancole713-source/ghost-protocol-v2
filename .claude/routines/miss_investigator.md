# Miss investigator -- 7:20am CT (8:20 ET), weekdays

The miss review of the PRIOR session runs from 6:00am CT and is logged as `EDGE_VIEW misses`.

1. Read the latest `misses` view. None (holiday, or not run yet): reply one line, stop.
2. Take up to 8 executable movers the system did NOT catch. For each, web-search why it
   moved and WHEN that became public (publish timestamp). Classify:
   DATA (price/coverage missing) · DETECTION (listed, never surfaced) ·
   RULE (surfaced, a frozen rule rejected it -- name the reason) ·
   UNPREDICTABLE (news after 9:05 ET) · PUMP/NO-NEWS (no findable catalyst).
3. Patterns across recent investigations (notes kind=miss_investigation if the connector
   works; else this session's earlier investigation replies).
4. A pattern that suggests a strategy is written as a PROPOSAL: a new, separately named
   hypothesis with rules computable point-in-time -- never a change to a frozen rule.
5. If `ghost_edge_note` is available: one note, kind=miss_investigation,
   author=miss-investigator, day=<session investigated>, symbols=[...].
6. Reply: a short table (symbol, move, cause, knowable before the card?, class) and one
   line of patterns. No push unless a DATA or DETECTION failure repeats 3+ days.
